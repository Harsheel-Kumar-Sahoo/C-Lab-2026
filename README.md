## <img src="https://api.iconify.design/lucide:folder-tree.svg?color=%230969da" width="24" height="24" align="center" alt="Folder tree icon" /> Repository Structure

Each lab is organized in its own folder. Every question has its corresponding C source file (`Qx.c`) paired with a screenshot of its output (`Qx_output.png` / `.jpg`).

```
C-Lab-2026/
│
├── Lab01/
│   ├── Q1.c
│   ├── Q1_output.png
│   ├── Q2.c
│   └── Q2_output.png

├── Lab02/

```

## <img src="https://api.iconify.design/lucide:terminal.svg?color=%230969da" width="24" height="24" align="center" alt="Terminal icon" /> How to Compile & Run

Each program can be compiled and executed using `gcc`:

```bash
gcc Qx.c -o Qx
./Qx
```

Replace `Qx` with the relevant question file name (e.g., `Q1`, `Q2`).
